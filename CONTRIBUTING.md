# Contributing to Sanctuary

Thank you for your interest in contributing to Sanctuary! We welcome bug reports, feature suggestions, and code contributions.

## Development Workflow

1. **Prerequisites**: Android Studio Ladybug or newer, JDK 17+, Android SDK 35.
2. **Cloning**:
   ```bash
   git clone https://github.com/ankur3-101106/bible.git
   cd bible
   ```
3. **Building**:
   ```bash
   ./gradlew assembleDebug
   ```
4. **Testing**:
   ```bash
   ./gradlew test
   ```

## Pull Request Guidelines
* Keep PRs focused on a single issue or improvement.
* Ensure all unit tests pass before submitting.
* Follow established Kotlin style conventions.
