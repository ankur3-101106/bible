# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting Vulnerabilities

If you discover a security vulnerability in Sanctuary, please report it via [GitHub Security Advisories](https://github.com/ankur3-101106/bible/security/advisories) or by opening a private issue.

Sanctuary processes all data locally on-device. No user data is collected or transmitted over network connections.
