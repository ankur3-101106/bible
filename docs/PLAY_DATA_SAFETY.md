# Google Play Data Safety Declarations

This document provides the exact answers for the Google Play Console **Data Safety** questionnaire based on the verified Sanctuary implementation.

## Data Collection & Sharing Summary

* **Data Collected**: **No Data Collected**. Sanctuary does not collect any user data off the device.
* **Data Shared**: **No Data Shared**. Sanctuary does not share any user data with third parties.
* **Data Security Practices**:
  * Data is processed and stored 100% locally on the device using Android's Room database.
  * Users can export or delete their local data at any time through application settings or by clearing application storage.
